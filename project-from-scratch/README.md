# Aussie EcoLens From Scratch Setup

This folder is a self-contained rebuild package for the multi-cloud serverless wildlife observation platform.

It contains the files and instructions needed to recreate:

- AWS Cognito authentication
- DynamoDB tables
- S3 upload bucket
- Lambda functions
- API Gateway HTTP API with Cognito JWT authorizer
- SNS tag notifications
- GCP Cloud Run ML tagging service
- AWS to GCP private access through Workload Identity Federation
- Frontend environment wiring

## Setup Order

Use this order. It avoids circular dependencies.

1. Copy `.env.example` to `.env` and fill values.
2. Create AWS Cognito user pool and app client.
3. Create DynamoDB tables.
4. Create S3 upload bucket and CORS.
5. Create Lambda execution IAM role.
6. Deploy GCP Cloud Run ML service.
7. Configure GCP Workload Identity Federation for AWS Lambda.
8. Package and deploy Lambda functions.
9. Add S3 ObjectCreated trigger for the media processor Lambda.
10. Create API Gateway HTTP API routes with Cognito JWT authorizer.
11. Configure SNS permissions and topic prefix.
12. Configure frontend `.env`.
13. Run end-to-end smoke tests.

## Environment Loading

Most scripts expect environment variables.

```bash
cd project-from-scratch
cp .env.example .env
set -a
source .env
set +a
```

On zsh this also works.

## End-to-End Smoke Test Checklist

After setup:

1. Create a Cognito user with email, first name, last name, and password.
2. Verify email.
3. Sign in to the frontend.
4. Upload an image.
5. Confirm upload goes `UPLOADED` to `READY`.
6. Confirm thumbnail URL is visible.
7. Confirm tags were generated by Cloud Run.
8. Upload a video.
9. Confirm one frame per second extraction, thumbnail from first frame, then ML tagging.
10. Search by tag/count.
11. Search by species.
12. Search by thumbnail URL.
13. Search by temporary query file.
14. Bulk add and remove a tag.
15. Subscribe to a tag.
16. Upload matching media and confirm SNS email flow.
17. Delete selected media and confirm original, thumbnail, frames, checksum, and DB record are removed.

## Important Security Notes

- Keep S3 private. Browser access uses pre-signed URLs.
- Keep Cloud Run private. AWS Lambda calls it through Workload Identity Federation.
- Attach Cognito JWT authorizer to every API route.
- Do not commit `.env`, model weights, AWS keys, or GCP service account keys.
- Service account key creation is not needed for this setup.

## Model Weight Files

The Cloud Run rebuild folder includes the required local model files:

- `gcp-cloudrun/model.pt`
- `gcp-cloudrun/mdv5a.pt`

They are intentionally ignored by git because they are large binary assets. If this folder is copied to another machine, copy those two files with it.
